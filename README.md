# Heat and mass transfer lib
Small library to calculate heat and mass transfers in heat exchangers or bubble columns.

I update this as I go to calculate different temperatures, saturations or pressures needed for my research.

## Usage
All heat and mass exchangers are built on the Heat_Exchanger class. The states of the medium can be calculated via the TILMedia Library or the CoolProp library.

CoolProp is not yet fully implemented
